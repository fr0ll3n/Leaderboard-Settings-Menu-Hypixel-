# LeaderboardSettings

Hypixel-style Bed Wars (can be for SkyWars, Build Battle etc.) leaderboard settings menu plugin.

**Version:** 1.0.12  
**Author:** fr0ll3n  
**API:** 1.13+

## Features
- Settings menu via `/lbsettings` (aliases: `lbsetting`, `leaderboardsettings`, `lbs`)
- PlaceholderAPI expansion for alignment (`%lbalign_*%`) (This is for the block setting for text alignment settings)!
- Soft-depends: LuckPerms, PlaceholderAPI

## Building
This is a standard Bukkit/Spigot plugin. Use Maven or Gradle with Spigot/Paper API dependency.
